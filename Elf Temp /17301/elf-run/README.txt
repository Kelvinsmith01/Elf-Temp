ELF RUN: Realm of the Skies
===========================
Open index.html in a browser (needs an internet connection the first time for
three.js r128 from cdnjs and the Google Fonts).

Controls
  Touch: swipe = lanes/jump/slide, double-tap or hold centre = fly
  Keys:  A/D or arrows, W/Space jump, S slide, double-tap Space or F = fly

Where to extend (all inside index.html, <script> section)
  THEMES, CHARS, UPG, BOOSTS  - data tables for worlds, elves, upgrades, shop
  Snd.assets                  - set e.g. jump:'jump.mp3' to replace synth sounds
  OB                          - obstacle factory
  ITEM                        - collectibles and power-ups
  World.populate              - spawn patterns / difficulty
